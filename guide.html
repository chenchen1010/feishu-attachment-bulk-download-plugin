四步完成下载

  1. 注册 Firefly 并获取 API Key

    新用户注册即送 200 积分。进入 Firefly 的 API Key 页面创建账户钥匙。

  2. 完成插件设置

    回到插件，点击“下载准备”右侧的设置按钮，粘贴 API Key 后完成设置。只有主动勾选时才会在当前浏览器记住 Key。

  3. 选择要下载的内容

    选择数据表、视图、附件字段和记录范围；需要整理文件时，可设置命名方式和分组方式。

  4. 开始下载

    选择 ZIP 下载可将多个字段一键打包；也可以选择直接下载原文件。
